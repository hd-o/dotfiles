# Minimum Viable Plan

Produce the minimum-sufficient implementation plan: the smallest
set of necessary changes that fully achieves the stated goal.
Describe only what must change and why each change is necessary,
excluding optional, speculative, future-oriented, generalized,
or enterprise-level work unless required by the goal. Favor the
narrowest correct scope and existing mechanisms, and include no
step whose omission would still leave the goal fully achieved.
